# Publication Project Notes

## Target Journal

Geosciences (MDPI)

## Section

Cryosphere

## Working Title

Integrated Remote Sensing Analysis of the Long-Term Evolution of a Glacier-Fed Moraine-Dammed Lake in the Northern Tien Shan: The Tosor Lake Case Study

## Scientific Focus

The paper investigates the long-term evolution of the Tosor glacier–lake system from 1973 to 2025 using integrated multi-temporal remote sensing, topographic, climatic, and field observations.

## Core Study Components

1. Long-term glacier retreat and glacier change (1973–2025).
2. Recent glacier-area changes and Tosor Lake area dynamics (2019–2025), including analysis of their temporal relationship.
3. Long-term topographic changes within the glacier–lake basin using KH-9, ALOS, and UAV-derived elevation data.
4. Changes in the lake drainage/outflow system.
5. Recent moraine-surface deformation using DInSAR, only after the results are fully validated.
6. Climatic influence using temperature, PDD, precipitation, and snowfall data.
7. UAV and field observations from 2025.
